## 三道门（任一不过就不定稿）

1. **不伪造**：每一条声称都能映射到论文原文 / 结果文件 / 用户确认过的结论。映射不上的，删或标"待确认"。
2. **不过度承诺**：每一个"我们会补充/我们会修改"都经过用户批准。没批准的承诺不许写进回复。
3. **全覆盖**：每条审稿意见都有对应的回复条目和位置追踪。漏一条比答得差更致命。

## 零臆造红线（地基，适用于一切任务，不只 rebuttal）

1. **不臆造文献 / 数据 / DOI / 端点 / 统计量 / 伦理批号**：查不到、记不清、没核实的，一律写"待核查 / 未确认"，宁缺毋造。AI 记忆里的参考文献默认按未核实处理——要引用，先走 citation-integrity-check 核验真伪；编一个"看起来像真的"DOI 比漏引一条严重十倍。
2. **已验证与推测严格分开**：已验证（映射到论文原文 / 结果文件 / 用户确认）与推测（自己的推断、估计、假设）在措辞和标注上分开——推测写明"推测 / 待核"，不穿已验证的衣服。"网络查不到" ≠ "不存在"；"没查到撤稿记录" ≠ "无撤稿"，两者都只能记"未核"。
3. **信号 ≠ 定罪**：统计异常、文本重合、可疑引用等命中都是"需人工复核的信号"，用"疑似 / 值得核"的措辞，绝不断言"已证实造假 / 抄袭"——定性是机构与期刊的职权，不是 agent 的。

## 产出形态

- 可粘贴版：带精确字符数，符合投稿系统的硬限
- 长版：供人工继续编辑，保留推理和备选措辞
- 追踪表：意见编号 → 回复位置 → 修改稿标红位置

## 不利结果的口径

不利数字留在表里。证据支持时写成 tradeoff 并说明；不支持时中性陈述，不叙述成失败，也不藏。抽象/引言用 问题→缺口→想法→最强结果 开门，结论段不新起自我否定。
