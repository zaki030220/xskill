## 一句话 + 分工

把返修当成一个有台账的工程，不是一封信：意见登记 → 原子分诊 → 证据绑定 → 承诺追踪 → 逐点成文。**成文是最后一层，不是第一层**——先有矩阵，再写 prose。

分工（三层不许混）：**事实层**（每条声称映射证据、承诺经批准、全覆盖）听 claim-safety-gates；**姿态层**（自信、不自我贬低、不防御性措辞）听 anti-defensive-writing；**本技能管流程层**——意见怎么拆、策略怎么选、承诺怎么追踪、响应信怎么组装。

## 硬规则（不许改软）

1. **审稿人原话逐字保留**。意见登记里存原文，不改写、不"翻译"、不省略；分诊标签、归因、回复草稿都是解释层，永远不替代原文。
2. **一句含两个独立要求 → 拆两条**，各自指向同一原文片段；不许把审稿人的话转述成新的"引文"。
3. **不发明任何东西**：实验、分析、引用、修改位置、行号、审稿人身份、期刊规则、结果。PLANNED 不能写成完成时；DONE 必须有真实的修改定位（稿件页/段/行），补做的实验还要有可核验的运行产物与数字。
4. **审稿人错了 ≠ 可以忽略**。用稿件定位 + 证据澄清；分歧重大时明确请编辑裁决（request editor ruling），不冷处理。
5. **审稿人要求与期刊政策 / 伦理 / 数据权利 / 预算冲突时，不默默照做**：标记拒绝（declined）或请裁决，绑定政策依据，审稿人原话照留。
6. **响应信字数与格式只按目标期刊当期规则核**；查不到就标 UNKNOWN 待核，不套用别家期刊的规则（哪怕是同一出版商）。
7. **全覆盖**：每条意见（含编辑意见和元审稿 meta-review，若有）都有对应回复条目。漏一条比答得差更致命。

## 工作流（五步）

### 1. 登记意见
逐字抄录每条审稿意见、编辑信、元审稿；记录来源（用户粘贴 / 邮件 / 投稿系统）、轮次、审稿人编号。用户没给全的材料如实记"未提供"，不猜。

### 2. 原子化分诊
一条原子 = 一个独立的 request / claim / question / misunderstanding / editorial 项。每条原子：
- **归因**（单选）：novelty（新颖性质疑）/ experiment（实验设计或证据）/ writing（表述）/ clarification（澄清即可）/ citation（引用）/ ethics（伦理）/ scope（范围）/ editorial（编辑性）
- **策略**（五选一）：
  | 策略 | 什么时候用 |
  |---|---|
  | 照改 acknowledge & fix | 意见成立，改稿件 |
  | 证据反驳 rebut with evidence | 意见基于误解，用已有证据澄清 |
  | 澄清 clarify | 纯表述问题，改措辞即可 |
  | 降级主张 downgrade claim | 意见部分成立，收缩声称范围 |
  | 请编辑裁决 request editor ruling | 与审稿人分歧重大、或审稿人之间意见相反 |

### 3. 绑定证据与修改
每条原子绑定：涉及的稿件 claim、支撑证据（真实存在的结果/文件/引用）、负责人、状态（PLANNED / IN_PROGRESS / DONE / 拒绝 / 不适用）。**修改定位只在稿件真改了之后填**；新引用先经核实再进回复。

### 4. 新实验请求门
任何"补个实验 / 补个数字"的要求，先过三问再动手：
1. **分类**：重新分析现有数据 / 最小改动 / 适配现有流程 / 需要新数据？
2. **可行性**：数据、时间、权限是否具备？
3. **授权**：用户是否批准（涉及新数据采集、人工试验、大算力时要单独确认）？

跑完且结果落地后，回复里才允许用完成时态。

### 5. 响应信成文
结构：开头一段感谢 + 主要修改概览 → 逐条【审稿人原话（引用格式）→ 我们的回应 → 修改位置（稿件页/段/行）】→ 结尾致谢。区分"已修改"与"我们认为不必改、但解释理由"两种措辞，不许混。成文后过一遍 claim-safety-gates 三道门 + 本技能自查清单。

## 承诺台账

| 意见编号 | 承诺内容 | 状态 | 修改定位 | 核验 |
|---|---|---|---|---|
| R1.2 | 补充敏感性分析 | DONE | 正文表 3 / P12 L8-L20 | 数字与结果文件核对 ✓ |

交付前逐行核：无一条 PLANNED 被写成完成时；每个 DONE 有定位且抽查两处回稿件原文验证。返修周期内改动的稿件数字，走 paper-claim-audit 的逐数字核对。

## 自查清单

- [ ] 每条意见（含编辑信与元审稿）有对应回复条目，无遗漏
- [ ] 审稿人原话逐字保留，回复里的"引文"都是真实原文
- [ ] 每条原子有归因、策略、状态；拒绝/不适用的有依据
- [ ] 所有 DONE 有真实修改定位；补做实验有可核验结果
- [ ] 新实验请求过了分类+可行性+授权三问
- [ ] 响应信字数/格式按目标期刊当期规则核过（或标 UNKNOWN）
- [ ] 无 PLANNED 写成完成时；无发明数字、行号、引用
- [ ] 与审稿人的分歧用证据回应，未冷处理、未自我贬低
