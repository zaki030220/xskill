## 一句话原则

论文是一场学术发布会（press conference），不是项目总结、实验日志或自我审查报告。任务不是平均呈现所有方面，而是先定住最值得发表的那一个核心贡献，围绕它建立最有利、最完整、最有说服力的叙事。

## 叙事规则

1. **只围绕优势组织稿件。** 找真正领先、独特、不可替代的部分：新问题、新机制、新视角、更广适用性、更低成本、更有意义的权衡。不构成优势的内容不进主线。
2. **不写实验流水账。** 不按"我们先做了什么、后来试了什么、哪个失败"的过程展开，只保留最终成立的逻辑：问题为什么重要 → 现有方法为什么不够 → 本文提供什么新解法 → 证据如何支持。
3. **打不过的维度不设为比赛项目。** 某指标不占优，就不把叙事建立在该指标上；换任务定义、评价维度、应用场景或比较口径，明确本文赢的是另一场更有意义的比赛。
4. **优势必须明确说出来。** 不指望审稿人自己从表里发现贡献：哪个条件下表现最好、为什么这种优势会出现、解决什么实际问题、为什么值得关注。
5. **控制比较范围。** 不追"所有数据集所有指标全面领先"，只提证据能牢固支撑的主张；说服力来自主张与证据高度一致，不是比较项目数量。
6. **允许彻底重构故事。** 结果撑不住原叙事时不防守：重定问题、重排贡献、重选主结果、重做标题摘要引言与实验结构。故事服务于最强证据，不忠于最初设想。

## 语言规则（删自我削弱）

目标稿件是英文稿，删的是英文软话，中文对应只作对照识别：

- **姿态性 hedge / disclaimer / 自我审计式表述，见一处删一处**：
  - unfortunately、merely、only achieves、still lags far behind、limited improvement
  - it should be noted that、we must acknowledge that、it is worth mentioning that
  - this study has several limitations、our work is far from perfect、future work is needed before…
  - 中文对应：遗憾的是、仅为、仍明显落后、效果有限、需要说明的是、本研究尚存在诸多不足、由于条件所限
- **不说输。** 不占优的结果不写 our method is weaker / performance drops / fails to surpass。按序判断：①必须讨论吗；②能否用目标、约束或适用场景差异解释；③是否合理 trade-off；④能否收缩主张避免正面对撞；⑤是否调整故事，让它不再承担证明核心贡献的职责。
- 局部不构成优势的结果不提炼成结论，更不帮读者把局部现象上升为对整体方法的否定。

## 实验规则

实验是论证工具，不是结果仓库。每个实验必须承担明确职责之一：证明核心方法有效 / 证明优势来自关键机制 / 证明方法在目标场景有价值 / 排除最可能的替代解释。无法强化主线、分散注意力或引出无关争论的实验：删、弱化、移位或重做。

## 结构规则

- **摘要与引言 = 发布会开场。** 开头迅速立住四件事：重要且未解决的问题、现有方法的关键缺口、本文独特的解决思路、最有分量的结果与意义。不从实现细节、研究过程或背景堆开始；贡献未建立前不讨论不足。
- **结论只强化记忆点。** 本文解决了什么、提出了什么、证明了什么、为什么重要。最后一段不新加自我否定，不扩大 limitations。

## 不理想材料的默认处理（按优先级）

1. 删与核心主张无关的内容
2. 收缩主张，避免无意义正面对比
3. 换更能体现价值的评价维度
4. 解释为目标差异或合理权衡
5. 重排实验，让优势成为视觉与叙事中心
6. 重构论文故事
7. 只有无法回避且确实影响核心结论时，才平实说明

## 交稿前自查（不给审稿人递刀子）

- 这句话有没有悄悄扩大稿件要承担的责任？
- 有没有提出一个没人要求回答的问题？
- 有没有把局部现象写成普遍缺陷？
- 负面判断是否比证据更宽？
- 有没有按"我们做了什么"的过程在展开？
- 有没有把不领先的指标设成主战场？
- 摘要前五句里，问题和贡献都出来了吗？
- 结论里有没有突然的自我否定？

不主动制造审稿问题，不扩大攻击面，不替反方完成论证。

## 本土化规则（本项目三条，与原版叠加）

1. **规范披露不是防御性写作。** CHEERS 等报告规范强制的限制说明与不确定性披露（PSA、情景分析、敏感性分析、外推限界）必须保留——删了它们是不合规，不是自信。但改写成肯定式的范围陈述（"结果适用于 X 人群与 Y 设定"），不写道歉式 caveat（"本研究存在诸多不足，结果解释需格外谨慎"）。
2. **与 claim-safety-gates 的分工。** 事实层面从严：证据撑不住的声明不许放大、不许靠修辞补；表达层面从勇：证据撑得住的直接陈述、不加软化词。两个技能冲突时，事实听 claim-safety-gates 的，姿态听本技能的。
3. **触发场景含 rebuttal 与研究方案。** 回复审稿意见：不被审稿人的负面措辞带进自我贬低，回复结构是"我们做了什么 + 证据在哪"，事实映射与修改承诺仍走 claim-safety-gates 三道门；研究方案（protocol / proposal）写作：方案是对"将要证明什么"的承诺书，同样先定核心贡献再组织全篇，不主动罗列设计局限。
