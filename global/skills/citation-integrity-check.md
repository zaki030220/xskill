## 一句话 + 分工

让每条作者实际使用的引用**真实、字段正确、与它支撑的声称诚实相连**。四个不同的问题分开判：格式对不对（NMA 审稿初审管）、元数据存不存在、出版完整性事实（撤稿/更正）、语义上是否支撑声称（本技能管后三个）。

分工：**nma-manuscript-audit 管引用编号/格式**的机械初审（编号错位、标点混用）；**本技能管真伪与支持度**——文献存在性、字段一致性、撤稿状态、声称-引文语义匹配。review-rebuttal 里新引入的引用也要走本技能核验。

## 红线（不许改软）

1. **不发明任何东西**：引用、DOI、作者、年份、期刊、定位、支持判定，一个都不许编。
2. **网络失败 ≠ 文献不存在**：超时、限流、5xx、需要登录、索引没搜到——一律记"查证不可用"，绝不记"该文献不存在"。
3. **"确认不存在"要双源**：只有当注册机构（Crossref/DataCite）明确报 404/410 且 DOI 系统确认未注册，才可标 CONFIRMED-MISSING；单源查不到只算未决。
4. **"确认存在"也要双源**：注册机构元数据 + 至少一个独立字段源（PubMed/Semantic Scholar/OpenAlex）都确认才算；否则保留"未决/不可用"。
5. **原样保留作者引用的字段值**：核出冲突时摆两边证据，不擅自用"最像的"检索结果覆盖作者原文；人来裁定。
6. **元数据确认 ≠ 语义支持**："A 引了 B"和"B 支撑声称 C"是两回事；SUPPORTS 必须读过引文对应位置（定位到页/段）才能给。

## 状态机（每条引用四选一）

| 状态 | 含义 | 动作 |
|---|---|---|
| CONFIRMED | 注册源+独立源都确认 | 可进参考文献表 |
| CONFIRMED-MISSING | 注册机构明确报不存在 | **critical**：删除或换文献 |
| UNAVAILABLE | 网络/限流/权限挡住了 | 换源重试，仍不行如实记 |
| UNRESOLVED | 证据不全或两源不一致 | 继续查证，不称"已核" |

## 工作流

### 1. 清点
从稿件正文、图表、补充材料把每处引用出现都列出来（citekey、原始标识符、出现位置），不只扫参考文献表——正文引了但表里没有的、表里有但正文没引的，都是发现。

### 2. 规范化（不抹版本）
DOI/arXiv/PMID/ISBN/URL 规范化；同一作品去重；**arXiv 版、录用稿、正式 DOI 版保留为同一作品的不同版本**（仅在输入明确建立关系时），关系不明确就分开标未决。

### 3. 双源核验
Crossref/DataCite（注册源）查 DOI 元数据；PubMed/ Semantic Scholar/OpenAlex（独立源）交叉核对题名/作者/年份/期刊。记录每个源的返回状态与时间。核验用的邮箱/密钥只用于请求，不写入任何产出文件。

### 4. 嵌合引用检测（AI 生成引用的高发伤）
真实 DOI + 冲突字段 = 疑似嵌合（把真 DOI 安到了不存在的文章头上）。判级：
- **critical**：真实标识符 + 题名/作者/年份至少两处冲突；或题名吻合但作者名单多出不存在的作者
- **warn**：单一字段出入（年份在线版/印刷版差、副标题、作者顺序、个别作者缺）——人工核后再定

### 5. 撤稿/更正核查
查 Crossref 的 updated-by/update-to 关系（方向别搞反：被更正的原文带 updated-by，更正启事带 update-to）。发现撤稿/更正/关注表达：记录事实，**撤稿文献可以保留作历史记录，但不能默默支撑现行结论**——要么换文献，要么在正文显式说明。措辞与伦理判断交作者。

### 6. 声称-引文支持度（五档）
对照引文原文（非摘要级臆测）逐条判：

| 档 | 含义 |
|---|---|
| supports | 引文定位处确实支撑该声称的原样表述 |
| partial | 只支撑一个更窄的说法（声称要收窄或拆分） |
| related_only | 同主题，但不是这个命题的证据（最隐蔽的滥用） |
| unsupported | 引文与声称矛盾或不支撑 |
| review_required | 全文/定位/审读人缺一样，先不判 |

判 supports 的前提：真读过引文对应位置、有定位（页/段）、支持判定可追溯。**只读过摘要就判 supports 是违规**——摘要级只允许在"摘要明确写出了该声称"时直接成立。判定时对齐方向、人群、干预、对照、指标、时长、因果强度——药物经济学里剂量、人群、对照错位是 related_only 的高发形态。

### 7. 交付
- 只把 CONFIRMED 且非嵌合的放进最终参考文献表 / BibTeX
- 失败与未决清单单独留档，不混进"已核"
- 修改建议给到"删/换/收窄声称"级，引用格式微调不归本技能

## 自查清单

- [ ] 正文、图表、补充材料的引用全部清点（含"正文有表里无"的反向核查）
- [ ] 每条 CONFIRMED 有注册源+独立源双重证据
- [ ] 网络失败的没有被记成"文献不存在"
- [ ] 嵌合检测跑过：真实 DOI + 字段冲突的都单列
- [ ] 撤稿/更正查过方向；撤稿文献未默默支撑现行结论
- [ ] 每个核心声称的引用有五档判定；related_only 没被当成 supports
- [ ] 摘要级判定只用于摘要明确含该声称的情况
- [ ] 无任何发明字段；作者原始引用值原样保留待裁
